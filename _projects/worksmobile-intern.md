## 프로젝트 개요

인턴십 토이 프로젝트로 관리자 기준 고객별 서비스 ON/OFF 가능한 게시판 서비스 개발

(메인 기능: 사진 태그시 얼굴 인식 기능 추가하여 자동으로 태그 기능 개발)

**기간**: 2020.01 ~ 2020.02

## 주요 기능

- 관리자 기준 고객별 서비스 ON/OFF 기능
- 사진 태그시 얼굴 인식 기능
- 자동 태그 기능

## 기술 스택

- SpringBoot
- JQuery
- JavaScript
- MySQL
- Java

## 역할

- 아마존 Rekognition의 얼굴 표정/감정분석, 얼굴 비교 기능을 활용해 얼굴 인식 기능 구현

## 결과

- 게시판 얼굴인식 서비스 개발
    - 얼굴 비교 기능을 이용해 신뢰도 일정 수준 이상 시 매핑된 아이디 태그를 추가하는 방향으로 구현
