## 프로젝트 개요

서비스 구간별 데이터 전달 값을 **자동 세팅하는 테스터를 개발**하여, 개발자 테스트 효율성 60배 개선 및 이력 관리 체계 구축

**기간**: 2025.10 ~ 2025.12 (3개월)

## 역할

- 개발 및 히스토리 관리를 위한 멀티 트랜잭션 테스터 개발

## 문제점

- 서비스별로 상이한 필드명과 데이터 개수로 인해, 다중 트랜잭션 테스트 시 데이터 세팅에 과도한 리소스 발생

## 해결 방법

- 선행/후행 전문 내 필드 매핑 정보를 JSON 스키마로 설계하여 DB화
    - 요청필드명, 응답필드명, 요청데이터의 substring 위치를 포함한 JSON 데이터를 CLOB 타입으로 저장
- 세부테스트, 전체테스트에 대한 설명 필드를 추가하여 개발자 테스트 의도 및 세부 테스트 케이스 내용을 기재하도록 설계

## 결과

- 테스트 데이터 생성 시간 **60배 단축(건당 10분 → 10초 내외)**
- 휴먼 에러에 의한 테스트 데이터 오류 제거
- 개발/테스트 이력의 자산화
    - 다중 트랜잭션 테스트케이스를 저장 함으로써 추후 개발 시 히스토리 파악에 용이하게 개선
