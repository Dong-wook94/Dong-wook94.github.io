## 프로젝트 개요

사내 AGIT 챗봇 개발(직원 근태 데이터를 활용한 부재중 알림 및 부재시 알림 재공유 서비스)

**기간**: 2020.07 ~ 2020.08

## 주요 기능

- 부재 직원 태그시 부재중 댓글
- 해당직원 복귀시 알림전송

## 기술 스택

- MySQL
- Java
- SpringBoot
- JPA
- Gradle
- SpringBatch

## 역할

- 챗봇 서비스 개발
    - 직원 근태 정보를 활용하여 부재한 담당자에 대한 태그시 알림
    - 부재한 담당자 복귀 시 알림

## 결과

- 챗봇 서비스 개발
    - 스케쥴링을 통해 30분간격으로 부재한 직원의 복귀여부 체크
    - JUnit 을 통한 단위 테스트 작성을 통해 기본적인 기능 테스트 수행
